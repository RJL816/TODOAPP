## 本次更新

### 训练循环修复
- 周计划改为按具体日期与循环起始日计算训练安排。8–14 天循环跨周后正确顺延，同一星期不再合并多个循环日，休息日不会误显示训练。
- 与今天页、训练页使用同一套日期查询逻辑，无需重建已有计划。

### 训练可以收起与恢复
- 开始训练后，返回仅收起记录页面，计时继续，动作、组数、次数、重量与时长自动保留。
- 各页面顶部新增进行中的训练条，点击「继续记录」即可恢复；重新打开应用也能恢复本地草稿。
- 「完成训练」保存正式记录并停止计时；「放弃本次训练」经过确认后清除草稿。补记训练同样可以暂存，但不会启动后台计时。
- 完成记录实时更新训练历史与热量收支；重复提交同一训练草稿不会重复计入训练与消耗。

### Android 训练悬浮钟表
- 主设置 → 训练计时 → 训练悬浮钟表，授权「显示在其他应用上层」后使用。
- 沿用拾序的暖白钟盘样式，显示训练已用时间与名称，可拖动，点击钟表或正在训练的通知返回记录。
- 与专注悬浮钟表独立运行，两者可以同时显示，完成其中一个不会停止另一个。
- 未开启悬浮窗也可使用应用内训练条与通知栏计时；部分手机需允许通知与后台运行。

## 下载与安装

Windows：`todo_app_v1.0.12-setup.exe` 或 `todo_app_v1.0.12-windows.zip`。

Android：`app-release.apk`（v1.0.12，versionCode 13）。覆盖安装保留原数据，无需卸载旧版。
