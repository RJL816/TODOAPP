## 本次更新

### 🛠 修复与优化
- **全部页面的边缘拉动**：将 Android 的轻微拖动回弹扩展到计划、生活、专注、AI 聊天和设置弹层等页面。滑到顶部或底部继续拉动时，玻璃组件保持自定义通透度，不再因系统拉伸滤镜变色。
- **AI Markdown 回复**：聊天正文支持标题、粗体、列表、引用、表格、代码块和链接，并保留文字选择复制；图片通过点击在浏览器查看。
- **平板玻璃设置**：修复部分辅助功能开启时百分比能变、玻璃外观却不变的问题；保留明确高对比度模式的可读性处理。

### 🍅 手机番茄钟
- 通知栏与锁屏显示计时，暂停冻结、恢复继续；倒计时结束发送系统提醒。
- 可选悬浮小窗显示当前阶段的剩余时间，支持拖动、点击返回；关闭小窗仍保留通知栏计时。
- 修复正计时暂停后重启恢复、休息阶段计时显示和重复完成记录问题。
- 补齐 Android 提醒接收器和重启恢复配置，增加通知与后台运行设置入口。

悬浮窗在「专注 → 计时设置」中开启，并需授予悬浮权限。通知弹窗、锁屏展示和提醒及时性受系统通知、勿扰、精确提醒权限及厂商后台设置影响。
