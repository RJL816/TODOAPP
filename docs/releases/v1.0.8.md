## 本次更新

### 🛠 修复
- **手机滑动透明度**：触摸、上下滑动、松手时，玻璃卡片与输入栏持续保持自定义通透度，不再突然变透明又恢复。
- **「今天」页边缘拉动**：修复滑到顶部或底部后继续拉动、保持按住时玻璃效果变化的问题，改为轻微拖动回弹，松手后正常复位。
- **AI 配置保存**：修复输入 API 地址、Key 或模型后直接测试仍使用旧值、保存 Key 按钮保存旧内容的问题；切换预设或数据开关不再丢失输入，关闭设置也会保存当前配置。
- **AI 接口兼容**：支持填写 API 基础地址或完整 Chat Completions 地址，避免重复拼接；不再为所有模型强制固定采样参数，并兼容文本块形式的返回内容。
- **思考模型等待**：移除连接测试额外的 20 秒限制，统一等待最多 180 秒；对已核验的官方思考模型使用轻量推理，测试中显示等待状态并防止重复点击。
- **AI 报错说明**：保留服务商的 HTTP 状态、错误码和详细原因，便于区分认证、模型权限、额度和地址问题；错误信息中回显的 Key 会隐藏。
- **Android 更新入口**：启动后的更新提示正确打开 APK 下载入口，不再误走 Windows 安装流程。
- **手动添加课程**：修复新增课程被归入旧学期、在当前课表中找不到的问题。
- **备忘录稳定性**：修复快速离开页面时，尚未结束的数据查询仍尝试刷新已关闭页面的问题。

## 更新方式

**已有更新检查功能的用户**：打开应用后会检查并提示新版本，也可进入「设置 → 关于与更新」手动检查。

- **Windows**：点击「下载并安装」覆盖更新；绿色版用户也可下载 ZIP，解压后运行。
- **Android**：下载 app-release.apk，按系统提示覆盖安装。旧版启动提示若无法正确下载，请从「设置 → 关于与更新」进入下载页，或直接下载本页 APK。

本次更新保留本地数据，无需卸载旧版。
